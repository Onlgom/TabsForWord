# Установка «Вкладки для Microsoft Word» — простая инструкция

Эта надстройка добавляет в Microsoft Word панель вкладок (как в браузере):
сверху каждого окна видно все открытые документы, по клику происходит
переключение, крестик закрывает документ, кнопка «+» создаёт новый.

Никаких специальных знаний не нужно. Права администратора не нужны.

(In English: [INSTALL_EN.md](INSTALL_EN.md).)

## Что нужно для работы

- **Windows 10 версии 1903 (май 2019) или новее, либо Windows 11.**
  На этих версиях всё необходимое (.NET Framework 4.8) уже встроено в систему —
  доустанавливать ничего не придётся.
- **Настольный Microsoft Word для Windows** (Microsoft 365, Word 2016 и новее).
  Надстройка не работает с Word Online (в браузере), Word для macOS и мобильным Word.

Если на компьютере более старая Windows, установщик сообщит об этом и подскажет,
что делать. Установка .NET Framework — разовая операция, и она требует прав
администратора (это требование Microsoft); самой надстройке права администратора
не нужны никогда.

## Установка (3 шага)

1. **Закройте Microsoft Word** (все окна; сохраните документы).
2. Откройте папку с программой и **дважды щёлкните файл `Install.cmd`**.
   Появится чёрное окно с сообщением «УСТАНОВКА ЗАВЕРШЕНА УСПЕШНО».
   Нажмите любую клавишу, чтобы закрыть окно.
3. **Запустите Word.** Сразу под лентой появится полоса вкладок — по одной
   вкладке на каждый открытый документ.

Если файлы программы вы получили в виде ZIP-архива — сначала распакуйте архив
целиком (правый клик → «Извлечь все…»), затем запускайте `Install.cmd`
из распакованной папки.

## Как пользоваться

- **Клик по вкладке** — переключиться на этот документ.
- **Крестик (×) на вкладке** — закрыть документ. Если есть несохранённые
  изменения, Word сам спросит, сохранять ли их — как обычно.
- **Кнопка «+»** — создать новый документ.
- **Точка рядом с именем** — в документе есть несохранённые изменения.
- **Правый клик по вкладке** — закрепить, закрыть, закрыть остальные, задать
  цвет, изменить размер вкладок или открыть папку с файлом.
- **Наведите курсор** на вкладку — увидите полный путь к файлу.
- **▾ справа** — список всех вкладок с поиском и пункт «Настройки…».
- **⌄ справа** — свернуть полосу вкладок; ⌃ возвращает её.
- **Ctrl+Tab / Ctrl+Shift+Tab** — следующая / предыдущая вкладка (можно
  отключить в настройках).
- Если вкладок много — сначала они сужаются, затем появляются стрелки ‹ ›
  для прокрутки.

## Язык

Надстройка берёт язык у **самого Word**: русский Word — русские вкладки, любой
другой — английские. Выбрать вручную: **▾ → «Настройки…» → «Язык»**
(Как в Word / English / Русский).

Установщик и Диагностика говорят на языке Windows. Задать явно:

```
powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1 -Lang ru
```

## Если вкладки не появились

Выполните по порядку, после каждого шага проверяя результат:

1. **Перезапустите Word** — полностью закройте все окна Word и откройте заново.
2. **Проверьте список надстроек Word:** Файл → Параметры → Надстройки →
   внизу «Управление: Надстройки COM» → «Перейти…». В списке должна быть
   «Вкладки для Word» с галочкой. Поставьте галочку, если снята.
3. **Проверьте отключённые элементы:** там же «Управление: Отключённые объекты» →
   «Перейти…». Если в списке есть наша надстройка или mscoree.dll — выделите
   и нажмите «Включить».
4. **Посмотрите лог:** откройте папку `%LOCALAPPDATA%\TabsForWord\Logs`
   (вставьте этот путь в адресную строку Проводника). Файл с сегодняшней датой
   покажет, загружалась ли надстройка и какие были ошибки.
5. **Переустановите:** закройте Word, запустите `Repair.cmd`; если не помогло —
   `Uninstall.cmd`, затем снова `Install.cmd`.
6. **Соберите диагностику:** запустите `Diagnostics.cmd` — на рабочем столе
   появится ZIP-файл с отчётом (версии Word и Windows, состояние установки,
   журналы работы). В отчёт попадают **имена и пути** ваших документов, имя
   компьютера и имя пользователя, но **не содержимое** документов. Внутри
   архива — обычные текстовые файлы: перед отправкой их можно открыть и
   просмотреть. Пришлите этот файл тому, кто дал вам программу, — по нему
   видно, в чём причина.

Ещё две частые причины:

- **Word запущен «от имени администратора»** — так надстройка не загрузится
  (установка выполняется для обычного пользователя). Запустите Word обычным
  двойным кликом.
- Файлы программы **скачаны из интернета и не распакованы** (запуск прямо из
  ZIP) — распакуйте архив и установите заново.

## Если панель ведёт себя странно — запасной вид

Обычно полоса вкладок встроена прямо в окно Word: её не отличить от самого
Word, документ сдвигается вниз ровно на высоту полосы. Это работает на всех
проверенных компьютерах, но опирается на внутреннее устройство окна Word,
которое Microsoft может однажды поменять.

Если панель не появляется, мигает или налезает на документ:

1. Запустите файл **«Classic-mode.cmd»** из папки с программой (той же, из
   которой запускали `Install.cmd`).
2. Перезапустите Word.

Панель переедет в отдельную полосу Word — со служебным серым заголовком сверху
(так выглядела программа до версии 1.6.0). Все возможности сохраняются.
Вернуть обычный вид: файл **«In-window-tabs.cmd»** и перезапуск Word.

Если пришлось так сделать — пришлите, пожалуйста, отчёт `Diagnostics.cmd`:
по нему видно, что именно не получилось.

## Word сохраняет документ при каждом переключении вкладки

Это **Автосохранение** самого Word, а не панель вкладок. Для документов,
которые хранятся в OneDrive или SharePoint, при включённом переключателе
**«Автосохранение»** (левый верхний угол окна) Word сохраняет ваши
изменения в тот момент, когда вы уходите из окна документа, — кликом по
вкладке, через Alt+Tab или кликом по другому окну. Поэтому пропадает точка
несохранённых изменений, и поэтому переключение может занять мгновение
(в наших проверках около четверти секунды): следующее окно выходит вперёд
только после того, как Word закончит сохранение. Без надстройки Word делает
ровно то же самое; сама надстройка документы не сохраняет и не меняет то, как
они сохраняются.

Если это не нужно:

- **Для одного документа:** выключите переключатель **«Автосохранение»** в окне
  этого документа. Word запомнит выбор для этого файла.
- **Для всех файлов:** Файл → Параметры → Сохранение → снимите флажок
  «Автосохранение файлов, хранящихся в облаке, по умолчанию в Word»
  (в разных версиях Word формулировка может немного отличаться).

После этого сохраняйте документ сами, через Ctrl+S. Защита от сбоев
(автовосстановление; в некоторых версиях флажок называется «Автосохранение
каждые N мин.») продолжает работать в любом случае и ваш файл не перезаписывает.

## Что важно знать (честные ограничения)

- Каждый документ по-прежнему открывается в собственном окне Windows — панель
  вкладок синхронно показывается в каждом окне и переключает между ними.
  «Физического» объединения окон в одно нет: современный Word такого не
  позволяет никаким официальным способом.
- Панель занимает сверху узкую полосу (примерно с одну строку текста, при
  масштабе 100% — 37 точек); область документа сдвигается вниз ровно на эту
  высоту. Кнопка ⌄ справа сворачивает полосу почти полностью. В запасном
  «классическом» режиме панель выше — около 1,5 см: там Word добавляет сверху
  собственный служебный заголовок, убрать который нельзя.
- Для документов в «Защищённом просмотре» (файлы из интернета) панель внутри
  самого жёлтого окна не показывается; в остальных окнах Word такой документ
  виден серой вкладкой, а после нажатия «Разрешить редактирование» она
  становится обычной.

## Технические детали (можно не читать)

Программа устанавливается только для текущего пользователя:
- файлы: `%LOCALAPPDATA%\TabsForWord` (сама надстройка и её настройки;
  `Classic-mode.cmd`, `Repair.cmd` и остальные .cmd-файлы остаются в папке,
  из которой вы устанавливали программу)
- реестр: ветки `HKCU\Software\Classes` (COM-класс) и
  `HKCU\Software\Microsoft\Office\Word\Addins\TabsForWord.Connect`
- журнал работы: `%LOCALAPPDATA%\TabsForWord\Logs`

Ничего системного не изменяется, другие пользователи компьютера не затрагиваются.
